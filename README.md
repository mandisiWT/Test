# My Portfolio

A simple one-page CV portfolio website for Mandisi Sikhakhane, an ICT and administration professional based in Pietermaritzburg. It covers what I do day to day, where I've worked, and what I'm currently learning.

This is a practice project for learning HTML, CSS and how to publish a site with GitHub Pages.

**Live site:** https://mandisiwt.github.io/my-portfolio/

## Built With

- HTML
- CSS
- Google Fonts (Bricolage Grotesque and Inter)
- GitHub Pages for hosting

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The page content and structure |
| `style.css` | Colours, fonts and layout |

## Run Locally

1. Clone the repo: `git clone https://github.com/mandisiWT/my-portfolio.git`
2. Open `index.html` in your browser.
